# Astryon Home

Astryon Home is a console-style entertainment platform.

Goals:
- Apple TV style interface
- Fetch-style live TV integration
- Xbox-style gaming experience
- Web apps for streaming services
- Proton/Wine support
- Windows fallback for incompatible software

## Structure

- source: Main application source code
- build: Build files
- apps: Application definitions
- services: Background services
- docs: Documentation
